How the model works

Why these four factors

  • TVL × 0.30 — the size of the prize. A token usually launches at a fraction of the value already locked in the protocol.
  • Growth — seven-day TVL change, clamped to −50%…+150%, weighted 0.60. Fast-growing protocols are where the next value is forming.
  • Maturity — days since DefiLlama began tracking, up to four years. A protocol that has run longer with no token has a bigger backlog of value to distribute.
  • Breadth — +3% per chain, up to six chains. Value spread across chains is harder to move and easier to keep.

What the board is not

  • It does not predict whether or when a token is issued.
  • It never ranks a protocol by name: the same function scores every row.
  • Wrapped, staked and bridged products of tokens that already trade are left out, as are exchanges and versioned pools of another protocol.
  • Farm steps are a starting plan, not financial advice. Never pay to claim an airdrop, and claim only from a link the protocol itself publishes.
